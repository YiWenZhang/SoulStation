
**接口 7 负责算分存库（写），接口 8 负责动态渲染（读）。**

---

### 🟢 核心交互流程 (Frontend Workflow)

1. **答题结束**：用户点击“提交”按钮  调用 **接口 7**。
2. **获取凭证**：接口 7 返回 `report_id` (报告ID)。
3. **路由跳转**：前端携带 `report_id` 跳转到结果页 (例如: `/result?id=101`)。
4. **页面渲染**：结果页在加载时 (`onMounted`)  调用 **接口 8** 获取完整展示数据。

---

### 1. 接口 7：提交测评 & 结算 (Submit)

**功能**：计算 SCL-90 得分，保存原始分数，**不生成**详细文案。
**调用时机**：用户做完最后一道题，点击“提交”时。

* **路由 (URL)**: `/api/assessment/questionnaire/submit`
* **方法 (Method)**: `POST`
* **请求头 (Headers)**: `Content-Type: application/json`

#### 请求参数 (Request Body)

```json
{
  "session_id": 123  // 当前答题会话的 ID
}

```

#### 成功响应 (Response 200)

```json
{
  "code": 200,
  "msg": "提交成功",
  "data": {
    "report_id": 101,        // 【关键】用于下一步调用接口8
    "risk_level": "moderate" // (可选) 风险等级: good/moderate/severe，用于做简单的弹窗提示
  }
}

```

#### 常见错误 (Error Codes)

| HTTP Code | 业务 Code | 错误信息 (msg) | 原因与前端处理 |
| --- | --- | --- | --- |
| **404** | 404 | 会话不存在 | `session_id` 传错了，或者该会话已被删除。 |
| **400** | 400 | 没有答题数据 | 用户一道题没做就点了提交。 |
| **400** | 400 | 还有 X 道题目未完成... | **校验失败**。前端应提示用户把题做完，不要跳转。 |
| **500** | 500 | 生成报告失败... | 服务器内部错误（数据库存入失败），提示用户重试。 |

### 2. 接口 8：获取报告详情 (Get Detail)

**功能**：根据 Report ID，动态读取分数并匹配最新的规则文案，生成完整报告。
**调用时机**：结果页加载时；或者在“历史记录”里查看旧报告时。

* **路由 (URL)**: `/api/assessment/report/detail`
* **方法 (Method)**: `GET`

#### 请求参数 (Query Params)

| 参数名 | 必填 | 说明 | 示例 |
| --- | --- | --- | --- |
| `report_id` | 是 | 接口 7 返回的报告 ID | `101` |
| `uid` | 是 | 当前登录用户的 ID (用于权限校验) | `5` |

**示例 URL**: `/api/assessment/report/detail?report_id=101&uid=5`

#### 成功响应 (Response 200)

| HTTP Code | 业务 Code | 错误信息 (msg) | 原因与前端处理 |

| **403** | 403 | 无权查看此报告 | **权限拦截**。当前登录用户试图查看别人的报告。 |

### 💡 给前端开发者的特别提示 (Tips for Frontend)

1. **关于雷达图 (`charts.radar_data`)**:
* 后端已经按照 ECharts 标准格式返回了 `name`, `value`, `fullMark`。
* 你不需要自己处理数据，直接丢进 `series.data` 即可。


2. **关于详情列表 (`dimensions_detail`)**:
* 这个数组包含了所有维度的分和文案。
* 建议用 `level_int` 来控制颜色：比如 `1=绿色`, `2=黄色`, `3+=红色`。


3. **关于 Markdown (`content.advice_md`)**:
* 这是后端根据规则动态拼装好的。
* 如果你想自己写样式，可以忽略这个字段，只用上面的 `dimensions_detail` 自己排版。
* 如果你想省事，直接用 `v-html` 或 Markdown 渲染库展示这个字段即可。
